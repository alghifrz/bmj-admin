# Buana Medika Jaya Admin

Next.js admin panel for Buana Medika Jaya. It talks to the Go API in `bmj-backend`.

## Run

1. Start the API from `bmj-backend` on port 8080.
2. Copy `.env.example` to `.env.local` if it is not already there.
3. From this folder, run `npm run dev`.

The panel is at [http://localhost:3001/login](http://localhost:3001/login). The public website can use port 3000.
